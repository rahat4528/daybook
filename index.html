Signature Architectural Innovations

Crafted for bilingual (Bangla & English) daily workflows with zero cloud latency.

📖

The Day Page & Event Stream

Every action taken across any module commits to an append-only event stream tagged with timestamp, mood, energy, and celestial sky code. Export anytime to PDF, Markdown, or JSON.

⏰

Wake Quest Native Alarm

Bypasses aggressive Android OEM task killers (MIUI, One UI, ColorOS) via native Kotlin Foreground Services, full-screen intents, and interactive challenges (Math, Simon Sequence, Steps, QR code, Bangla Voice).

৳

Bangladeshi Dhar & Paisa Ledger

Strict integer paisa precision (1 BDT = 100 paisa) completely eliminates floating-point drift. Tracks who owes you money and who you owe with micro-repayments and CSV export.

🧠

SuperMemo SM-2 Spaced Repetition

Integrated Student Mode with dynamic Easiness Factor calculation, review interval scheduling, exam seat plan tracking, and urgent countdown reminders.

☀️

Living Monochrome Sky

Computes real-time astronomical solar elevation angles and astronomical phases with offline Open-Meteo weather caching. Clean line-art aesthetic drawn on pure OLED black.

🛡️

Zero-Knowledge Ciphertext Cloud Sync

Keys derived via PBKDF2-HMAC-SHA256 (100,000 rounds). The NestJS sync backend stores only authenticated blind ciphertext envelopes with Last-Write-Wins (LWW) conflict resolution.
